# Third-party frontend assets

All frontend dependencies used by the HR panel are stored locally so the deployed UI does not depend on a CDN.

| Package | Version | License | Local purpose |
| --- | ---: | --- | --- |
| Bootstrap | 5.3.8 | MIT | RTL layout and UI primitives |
| Bootstrap Icons | 1.13.1 | MIT | Interface icons |
| Chart.js | 4.5.1 | MIT | Dashboard charts in a later phase |
| SweetAlert2 | 11.26.25 | MIT | Accessible confirmations and operation feedback |
| Jalali Date Picker (`@majidh1/jalalidatepicker`) | 1.0.0 | MIT | Persian/Jalali date input |
| Vazirmatn | 33.0.3 | SIL Open Font License 1.1 | Persian interface typography |

The original license text for each dependency is included in its local package directory.
